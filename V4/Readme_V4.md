# V4

### 新增

1.新增系统公告：
系统公告只会在登陆后弹出，关闭后本次登录期间不再弹出，如有需要，需重新登录才可查看。

2.新增通过邮箱添加好友的方式；

3.新增在联系人导航中，删除好友：

A用户删除B用户后，B用户界面也会自动同步，使A用户消失。

4.当忘记密码找回密码时候，用户名也忘记了，此时可以通过输入注册时候的邮箱来找回密码；

5.登陆时，除了使用用户名+密码，新增了邮箱号+密码登录；

6.新增超级管理员账户，每个新注册用户自动添加管理员进行管理交流。



##### 注：新增自动添加超级管理员，为了安全起见，同样将超级管理员信息录入到.env里了，新的.env如下：

\# 邮箱配置（用于发送验证码）

QQ_EMAIL=你自己的邮箱

QQ_MAIL_PASSWORD=你自己的授权码



\# 超级管理员账户（请务必修改为强密码！）

SUPER_ADMIN_USERNAME=用户名

SUPER_ADMIN_PASSWORD=密码
